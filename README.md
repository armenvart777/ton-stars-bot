# ton-stars-bot

Исходники Telegram-бота для анализа покупок Telegram Stars через TON. В [bot.py](bot.py) есть меню, выбор кошелька, настройки уведомлений, целей и регулярного отчета.

Запросы к TON API и разбор транзакций оставлены заглушками в [ton_api.py](ton_api.py), расчеты в [analytics.py], графики и PDF в [charts.py]. В текущем виде бот не получает данные для статистики и отчета.

## Запуск

Точка входа описана в [bot.py](bot.py), параметры окружения в [.env.example](.env.example). Списка в [requirements.txt](requirements.txt) недостаточно даже для импорта, так как `charts.py` использует matplotlib. Для сквозного запуска нужны реализации сбора данных, расчетов и графиков.
